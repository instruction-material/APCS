# For loop practice worked reference

Run `javac Main.java && java Main`.

With `Fern` and `3`, the first sequence has three names, the second has four 3s, and the countdown is 3, 2, 1, 0. The supplied product is 362880. The positive and negative maxima are 9 and -4. With count 0, there are no name lines and the countdown prints 0.
