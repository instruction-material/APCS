# Practice with arrays reference

Run `javac *.java && java Main`.

Use array traversal for an accumulator, a search, and a result array. The supplied squares example covers indices from 0 through 9.

For [2, 0, -3, 2], the ends match, the sum is 1, and the array contains zero. For an empty input those results are false, 0, and false. Count characters in ["sun", "", "sky"] to get 6. Generate three values in [0, 10) with a repeatable seed. As optional practice, reverse into a new array and swap the first minimum and maximum in the original array.
