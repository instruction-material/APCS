# While and nested loops reference worked reference

Run `javac Main.java && java Main`.

The `while` loop prints Practice ten times. The nested loops visit 12 cells. The three rows run from `(0,0) (0,1) (0,2) (0,3)` to `(2,0) (2,1) (2,2) (2,3)`. Moving the newline into the inner loop would put each cell on its own line.
