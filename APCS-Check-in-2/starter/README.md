# Methods and Control Structures Check

Implement `countMultiples` to count numbers between two inclusive bounds that are divisible by a supplied positive integer. Both bounds are between -10000 and 10000, and the upper bound is at least the lower bound. Write one prediction without running the program first.

Attempt the prompt before comparing with the reference.

Use JDK 17 or later. Compile with `javac Main.java`, then run `java Main`.

## Checks

Multiples of 3 from 1 through 12 give four. Multiples of 2 from -4 through 4 give five, including zero. A range consisting only of 5 contains one multiple of 5. From 1 through 3 there are no multiples of 5.
