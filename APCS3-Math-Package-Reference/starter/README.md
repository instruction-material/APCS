# Math package reference starter

Run `javac Main.java && java Main`.

Read the declarations before running. Record the number and type stored by abs, pow, and sqrt. Then compare an integer cast with rounding the square root.

The integer absolute value is 9, the double square is 9.0, and the square root of 15 is between 3 and 4. Casting to int gives 3. Rounding to the nearest integer gives 4.
