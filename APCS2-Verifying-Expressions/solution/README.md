# Verifying Expressions worked reference

Run `javac Main.java && java Main` in this folder.

The eight labeled results are false, true, 40, true, false, false, true, and false. Numeric comparison can compare an int and a double. Casting 35.5 to int discards the fraction, and assigning a Boolean to another Boolean preserves its value. The right-hand test in check 8 is skipped because its divisor is zero.
