# Math demo solution

Run `javac Main.java && java Main`.

Combine Math.pow, Math.sqrt, and Math.abs in a console program that labels each result.

Use bases from 1 through 20, powers from 0 through 8, and signed values from -10000 through 10000. Input 2 4 -7 gives power 16.0, square root 4.0, fourth root 2.0, and absolute value 7.
