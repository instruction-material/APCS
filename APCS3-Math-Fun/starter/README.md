# Math demo starter

Run `javac Main.java && java Main`.

Enter a base, a power, and a signed value. The power calculation is supplied. Pass its result to sqrt, then take the square root again for the fourth root. Find the absolute value of the third input.

Use bases from 1 through 20, powers from 0 through 8, and signed values from -10000 through 10000. Input 2 4 -7 gives power 16.0, square root 4.0, fourth root 2.0, and absolute value 7.
