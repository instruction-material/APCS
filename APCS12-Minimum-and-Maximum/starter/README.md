# Minimum and Maximum Search

Accept an ArrayList of boxed integers and find both extremes in one traversal. Use the opposite Integer constant for each starting candidate and handle an empty list first.

Complete the TODOs before comparing results with the checks. Compile with `javac Main.java`, then run `java Main` using JDK 17 or later.

`[-8, -2, -15]` gives `-15, -2`. `[9, 3, 9]` gives `3, 9`, and `[5]` gives `5, 5`. The empty case reports that there are no values. Explain why starting the maximum at zero can fail.
