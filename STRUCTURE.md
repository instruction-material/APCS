# APCS Structure

This repository backs `AP Computer Science A` and selected Java with/without
Graphics cross-links from the live course catalog. Historical folder names
remain, but each active project now uses the common wrapper shape.

Active public folders stay at the repository top level and contain
`README.md`, `starter/`, and `solution/`. Folders not linked by the live catalog
on 2026-05-14 were moved to `_archived-unlinked/` and should not be treated as
active course projects unless they are restored and linked in the course site.

Some migrated projects have only one real legacy snapshot; the opposite role
folder contains a README placeholder until a distinct starter or solution is
authored.

New AP Computer Science material should use the wrapper shape. Do not add
unlinked variants beside active folders.
