# Student class starter

Run `javac Main.java Student.java && java Main`. Each object prints its starting grade. Begin with grades 1–13, where 13 represents college.

Complete `getSchoolType`: grades 1–5 are elementary, 6–8 are middle, 9–12 are high school, and 13 is college. Then complete `passGrade` so grades 1–12 advance by one and 13 stays fixed. Keep the grade inside each object.

Trace the starting and ending grade and school type for 5, 8, 12, and 13. Advancing one record should never change a different record. Add two records in the same grade, advance one, and compare them.
