# Hospital survey starter

Run `javac Main.java && java Main`, then enter the example input in the console.

The starter reads the code and wait. Add a call to nextLine after nextInt to consume the rest of that line. Then read the comment with nextLine and the final field with nextBoolean. Print all four values with clear labels. Use fictional inputs.

Enter these four lines:

```text
PRACTICE-17
12
Sample queue comment
true
```

The output should preserve the complete comment, report a wait of 12, and print true for the final field.
