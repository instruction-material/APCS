# Hospital survey solution

Run `javac Main.java && java Main`, then enter the example input in the console.

Read a fictional practice record containing a text code, a whole-number wait, a multiword comment, and a true or false field.

Enter these four lines:

```text
PRACTICE-17
12
Sample queue comment
true
```

The output should preserve the complete comment, report a wait of 12, and print true for the final field.
