# Practice with ArrayLists reference

Run `javac *.java && java Main`.

Distinguish methods that inspect a list, return a new list, and change the list passed as an argument.

For [3, 2, 5, 2, 7], the even count is 2, the sum is 19, and removing the last even produces [3, 2, 5, 7]. Filtering ["", "apple", "class", "ant"] gives ["apple", "ant"] in a new list. Replace [-2.5, 0.0, 6.5] in place with [-1.0, 0.0, 1.0]. Check an empty list and a list with no even numbers.
