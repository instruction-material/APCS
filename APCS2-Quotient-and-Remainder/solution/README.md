# Quotient and remainder solution

Run `javac Main.java && java Main`, then enter the example input in the console.

Divide the first integer, the dividend, by the second integer, the divisor. Use / and % to obtain the quotient and remainder.

Enter `17 5` for quotient 3 and remainder 2, then `12 4` for quotient 3 and remainder 0. For `-17 5`, Java gives quotient −3 and remainder −2. Enter `7 0` to check the guard. Use integers from −10000 to 10000.
