# Store Class starter

Run `javac Main.java Store.java && java Main` in this folder.

Open `Main.java` and `Store.java`. The apple branch and inventory lookup are supplied. Add pear and hose branches using their unit prices of 7 and 15. Deduct stock only for positive quantities at or below the available stock. Return 0 for an unavailable item, a nonpositive quantity or an order above stock.
